# AD-TR-01 — Phase 2E-1 — Minimum Recognition Capability

## 1. Latar Belakang

Phase 2E telah menghasilkan evidence bahwa proses recognition merupakan tanggung jawab yang berbeda dari orthographic resolution.

Setelah pemisahan tersebut ditemukan, pertanyaan berikutnya adalah:

> Apa kemampuan minimum yang benar-benar harus dimiliki Recognition Layer?

Pertanyaan ini harus dijawab sebelum menentukan:

- class;
- API;
- internal data structure;
- perubahan ScriptPack;
- production implementation.

Tujuan Phase 2E-1 adalah mendefinisikan capability berdasarkan evidence, bukan menentukan implementasi terlalu dini.

---

# 2. Tujuan

Phase ini bertujuan untuk menentukan:

```text
WHAT Recognition Layer MUST DO
```

dan secara eksplisit membedakannya dari:

```text
HOW Recognition Layer WILL BE IMPLEMENTED
```

---

# 3. Evidence Dasar

Evidence berasal dari eksperimen sebelumnya terhadap:

```text
nga
ngka
angka
kang
hanacaraka
nya
nyka
kany
ngny
ngnyka
```

Eksperimen tersebut melibatkan:

- character-by-character recognition;
- fixed pattern recognition;
- longest known pattern recognition;
- Recognition Candidate;
- context classification;
- data-driven candidate recognition;
- candidate extensibility;
- candidate boundary exploration.

---

# 4. Capability A — Sequential Input Processing

Recognition harus mampu menerima dan memproses input sebagai sequence.

Contoh:

```text
hanacaraka
```

Recognition melakukan scanning secara berurutan.

Hasilnya dapat berbeda bergantung pada Recognition Knowledge yang tersedia.

Contoh:

```text
ha + na + ca + ra + ka
```

atau representasi lain apabila knowledge yang tersedia berbeda.

### Keputusan Capability

Recognition Layer wajib mampu:

```text
✓ menerima text sequence
✓ melakukan sequential scanning
✓ mempertahankan urutan hasil
```

Recognition tidak boleh mengasumsikan seluruh input harus langsung dikenali sebagai satu unit.

---

# 5. Capability B — Knowledge-Driven Matching

Recognition tidak boleh mengandung aturan script-specific seperti:

```python
if text.startswith("nga"):
    ...
elif text.startswith("ng"):
    ...
```

Pendekatan tersebut menyebabkan Generic Core mengetahui detail script tertentu.

Sebaliknya:

```text
Recognition Engine
        +
Recognition Knowledge
```

harus menjadi dasar proses matching.

### Keputusan Capability

Recognition Layer wajib:

```text
✓ menerima atau menggunakan knowledge eksternal
✓ melakukan matching terhadap knowledge tersebut
✓ tidak memiliki hard-coded script-specific pattern
```

---

# 6. Capability C — Longest-Match Selection

Eksperimen menunjukkan bahwa beberapa pattern dapat memiliki overlap.

Contoh konseptual:

```text
n
ng
nga
```

Untuk input:

```text
nga
```

Recognition harus mampu memilih:

```text
nga
```

apabila `nga` tersedia sebagai pattern lengkap.

Prinsipnya:

```text
Available Matches
        ↓
Select Longest Valid Match
```

### Keputusan Capability

Recognition Layer wajib mendukung:

```text
✓ pattern overlap
✓ longest-match selection
```

Urutan penyimpanan pattern tidak boleh secara diam-diam menjadi semantic rule.

---

# 7. Capability D — Explicit Classification

Hasil recognition harus membawa classification.

Classification minimum yang telah dieksplorasi adalah:

```text
KNOWN_COMPLETE_PATTERN
RECOGNITION_CANDIDATE
UNKNOWN_FALLBACK
```

Contoh:

```text
ngka
```

dapat direpresentasikan:

```text
ng → RECOGNITION_CANDIDATE
ka → KNOWN_COMPLETE_PATTERN
```

Classification memungkinkan tahap berikutnya mengetahui sifat setiap hasil tanpa harus mengulang recognition.

### Keputusan Capability

Recognition Layer wajib:

```text
✓ memberikan classification terhadap recognized pattern
✓ mempertahankan classification dalam hasil
```

---

# 8. Capability E — Unknown Preservation

Eksperimen menunjukkan bahwa input yang tidak ditemukan dalam Recognition Knowledge tidak boleh hilang.

Contoh konseptual:

```text
x
```

harus tetap dapat direpresentasikan sebagai:

```text
x → UNKNOWN_FALLBACK
```

Recognition tidak bertugas menentukan apakah input tersebut merupakan error final.

Keputusan tersebut dapat menjadi tanggung jawab layer berikutnya.

### Keputusan Capability

Recognition Layer wajib:

```text
✓ mempertahankan unknown information
✓ tidak membuang input tanpa representasi
```

---

# 9. Capability F — Ordered Sequence Preservation

Recognition Result harus mempertahankan urutan unit.

Contoh:

```text
angka
```

dapat menghasilkan:

```text
a
ng
ka
```

Urutan tersebut merupakan bagian penting dari informasi.

Resolution Layer dapat menggunakan posisi dalam sequence untuk memperoleh context.

Contoh konseptual:

```text
previous
current
next
```

dapat diturunkan dari posisi unit.

Karena itu Recognition Result tidak harus menyimpan previous dan next secara redundan.

### Keputusan Capability

Recognition Layer wajib:

```text
✓ menghasilkan ordered sequence
✓ mempertahankan urutan input representation
```

---

# 10. Capability yang Tidak Termasuk

Recognition Layer tidak bertanggung jawab terhadap:

```text
✗ final orthographic interpretation
✗ final transliteration output
✗ linguistic validation
✗ script-specific semantic decision
✗ UI message generation
✗ final error policy
```

Batas ini diperlukan untuk mencegah Recognition Layer berkembang menjadi monolithic transliteration engine.

---

# 11. Minimum Recognition Contract

Secara konseptual Recognition membutuhkan:

```text
INPUT
    +
RECOGNITION KNOWLEDGE
```

dan menghasilkan:

```text
ORDERED RECOGNITION SEQUENCE
```

Setiap recognition unit minimal membawa:

```text
value
classification
```

Bentuk implementation belum diputuskan.

Belum ditentukan apakah hasil akan menggunakan:

- class;
- dataclass;
- dictionary;
- tuple;
- immutable object.

