# Javanese ScriptPack

Official Javanese ScriptPack for the Aksara Nusantara ecosystem.

This ScriptPack provides support for the traditional Javanese writing system (Hanacaraka) through the standard ScriptPack interface defined by AN-STD-001.

---

# Overview

This package contains:

- Script metadata
- Character definitions
- Transliteration rules
- Font resources
- Audio resources (future)
- Educational assets (future)

The package is designed to be loaded by the Aksara Nusantara Core Engine.

---

# Writing System
